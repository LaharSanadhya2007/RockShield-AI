# GeoCrack Dataset

Primary training dataset for ROCKSHIELD AI rock-fracture semantic segmentation.

Dataset:
GeoCrack: A High-Resolution Dataset For Segmentation of Fracture Edges in Geological Outcrops

DOI:
10.7910/DVN/E4OXHQ

The dataset contains geological outcrop images and corresponding manually annotated fracture-edge masks.

ROCKSHIELD will use the dataset for research and development of its crack/fracture segmentation component.

Dataset files are not stored directly in the ROCKSHIELD Git repository.
